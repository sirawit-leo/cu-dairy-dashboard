# CU Dairy Research Farm — Milk Quality Dashboard

แดชบอร์ดคุณภาพน้ำนมดิบ ฟาร์มโคนมเพื่อการวิจัย จุฬาลงกรณ์มหาวิทยาลัย ปี 2569

**เปิดดูแดชบอร์ด → https://sirawit-leo.github.io/cu-dairy-dashboard/**

---

## เกี่ยวกับ

แดชบอร์ดหน้าเดียว แสดงผลการตรวจคุณภาพน้ำนมของฟาร์ม ครอบคลุม:

- คุณภาพน้ำนมรายตัว (SCC, องค์ประกอบน้ำนม, MUN ต่อโปรตีน)
- คุณภาพน้ำนมรวมถัง (TPC, LPC, Coliform) และ**เทียบผลของสหกรณ์กับถังนมของฟาร์ม** (SCC, %Fat, %SNF)
- เต้านมอักเสบ — แยก**รายใหม่/รายเดิม** และ**แยกลำดับการให้นม** (ท้อง 1 / 2 / 3 ขึ้นไป)
- **ประวัติสัตวแพทย์ครบทุกเหตุการณ์รายตัว** — เต้านมอักเสบ, ปัญหาสุขภาพอื่น, งานประจำ
- ภาวะคีโตซิส
- อาหาร DMI พลังงาน และน้ำหนักตัว พร้อม**ค่าที่ต้องการ (requirement)** เทียบข้างค่าที่วัดได้
- สุขอนามัยตัวโค การรีดนม และสภาพปลายหัวนม

## ข้อมูล

- รอบเก็บตัวอย่าง: ทุก 14 วัน
- ช่วงข้อมูล: มกราคม – สิงหาคม 2569 (2026)

## เกณฑ์ที่ใช้

| รายการ | เกณฑ์ | ที่มา |
|---|---|---|
| Subclinical mastitis | SCC ≥ 200,000 cells/mL | NMC |
| SCC รุนแรง | ≥ 500,000 cells/mL | NMC |
| TPC มาตรฐานน้ำนมดิบไทย | ≤ 500,000 cfu/mL | มาตรฐานไทย |
| Fat ขั้นต่ำ | 3.2% | มาตรฐานรับซื้อไทย |
| SNF ขั้นต่ำ | 8.25% | มาตรฐานรับซื้อไทย |

## ข้อควรระวังในการอ่าน

- **เครื่องบันทึกน้ำนมเสีย 27 เม.ย. – 16 ก.ค. 2569** ไม่มีข้อมูลน้ำนมรายตัวเลยในช่วงนี้
  ค่าที่แสดงในช่วงดังกล่าวเป็น**ค่าประมาณ** จาก Wood's lactation model ที่ fit กับวันที่วัดจริง
  ทั้งสองฝั่งของช่วงที่ขาด และมีเครื่องหมาย `≈` กำกับไว้ทุกจุด (คลาดเคลื่อนเฉลี่ย 2.6 กก./วัน)
- **น้ำหนักตัวหยุดบันทึกตั้งแต่ 27 เม.ย. และไม่กลับมาอีกเลย** ค่าน้ำหนักระหว่าง เม.ย. ถึง ส.ค.
  เป็นค่าประมาณเชิงเส้นระหว่างการชั่งจริงสองครั้ง
- **ตัวอย่างที่ผิดปกติ 15 ตัวอย่าง** (SCC นับไม่ได้ / ค่าที่เป็นไปไม่ได้) ถูกตัดออกจากทุกกราฟอัตโนมัติ
- **ไม่มีการบันทึกผลการรักษา** ที่ใดเลย ตัวเลข "หาย" ทั้งหมดคือการที่ SCC ลงต่ำกว่าเกณฑ์
  ระหว่างการตรวจสองครั้ง ไม่ใช่การหายทางคลินิก

## เทคนิค

ไฟล์ HTML เดียวจบ ไม่มี dependency ภายนอก ไม่เรียก network
เปิดจากไฟล์ในเครื่องได้โดยตรง ใช้งานแบบ offline ได้ รองรับทั้งจอคอมพิวเตอร์และมือถือ
และมีทั้งโหมดสว่างและโหมดมืด

## อัปเดตข้อมูล

1. สร้างไฟล์ dashboard ใหม่จาก xlsx
2. เปลี่ยนชื่อเป็น `index.html`
3. อัปโหลดทับใน repo นี้ (Add file → Upload files)
4. Commit — เว็บจะอัปเดตเองภายใน 1-2 นาที
